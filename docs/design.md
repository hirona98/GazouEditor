# 画像編集ツール設計書

## 概要

本ツールは、ブラウザ上で完結する画像編集ツールである。ユーザーはベース画像を読み込み、ベース画像の上下に配置された編集レイヤーへ画像、テキスト、図形、線を追加して編集する。編集結果はPNG画像として書き出す。

本ツールはGitHub Pagesで公開する静的Webアプリケーションとして構成する。サーバー処理、ユーザー認証、外部APIキー、パスワードを必要としない。

## 目的

本ツールは、既存画像を直接破壊せず、上下のレイヤーに注釈、装飾、図形、手描き線を重ねて編集できる環境を提供する。インストール不要で利用できることを重視し、ブラウザのみで画像読み込み、編集、書き出しを完結させる。

## 対象環境

- 公開環境はGitHub Pagesとする。
- 実行環境はブラウザとする。
- 対象ブラウザは最新版のChrome、Edge、Safari、Firefoxとする。
- 入力デバイスはマウス、タッチパネル、キーボードとする。
- 日本語入力はブラウザ標準のIMEを使用する。

## 機能要件

### 画像読み込み

- ユーザーはローカルファイルからベース画像を読み込む。
- 読み込んだ画像はベースレイヤーとしてキャンバスに配置する。
- ベース画像の表示サイズはキャンバスに収まるよう初期調整する。

### ベースレイヤー

- ベースレイヤーは編集不可とする。
- ベースレイヤーは移動、回転、拡大、縮小、削除、描画、塗りつぶしの対象にしない。
- ベースレイヤーはレイヤーパネル上で固定レイヤーとして表示する。

### 編集レイヤー

- 初期状態でベースレイヤーの上に編集レイヤーを1つ作成する。
- 初期状態でベースレイヤーの下に編集レイヤーを1つ作成する。
- ユーザーは編集レイヤーを追加できる。
- ユーザーは編集対象のレイヤーを選択できる。
- ユーザーは編集レイヤーの表示と非表示を切り替えられる。
- ユーザーは編集レイヤーの重なり順を変更できる。

### オブジェクト追加

- ユーザーは編集レイヤーへ画像を追加できる。
- ユーザーは編集レイヤーへテキストボックスを追加できる。
- ユーザーは編集レイヤーへ四角形、円、直線を追加できる。
- ユーザーは編集レイヤーへ手描き線を追加できる。
- 追加したオブジェクトは所属レイヤーに紐づけて管理する。

### オブジェクト編集

- ユーザーはオブジェクトを選択できる。
- ユーザーは選択中のオブジェクトを移動できる。
- ユーザーは選択中のオブジェクトを回転できる。
- ユーザーは選択中のオブジェクトを拡大、縮小できる。
- ユーザーは文字、線、図形の色を変更できる。
- ユーザーは選択中のオブジェクトを削除できる。

### テキスト編集

- テキストボックスはテキスト入力を受け付ける。
- テキストボックスはIMEを使った日本語入力に対応する。
- ユーザーはテキストのフォントを指定できる。
- ユーザーはテキストの文字色を指定できる。
- テキストはテキストボックスの大きさに応じて表示サイズを自動調整する。

### 描画

- ユーザーはマウスのドラッグ操作で線を描ける。
- ユーザーはタッチパネルを指でなぞって線を描ける。
- 線には複数の線種を用意する。
- 線種には通常線を含める。
- 線種には一定時間同じ位置に留まると線幅が太くなる線を含める。
- ユーザーは線の色を指定できる。
- ユーザーは線の太さを指定できる。

### バケツツール

- ユーザーはバケツツールで閉じた領域を塗りつぶせる。
- 塗りつぶし色はユーザーが指定した色を使用する。
- バケツツールは選択中の編集レイヤーを対象とする。
- ベースレイヤーはバケツツールの変更対象にしない。

### 書き出し

- ユーザーは編集結果をPNG画像としてダウンロードできる。
- PNG書き出しには表示中の全レイヤーを反映する。
- 非表示レイヤーはPNG書き出しに含めない。

## 画面構成

画面は次の領域で構成する。

- キャンバス領域
- ツールバー
- レイヤーパネル
- プロパティパネル

### キャンバス領域

キャンバス領域はベース画像と編集レイヤーの内容を表示する。ユーザーはこの領域でオブジェクトの選択、移動、変形、描画、塗りつぶしを行う。

### ツールバー

ツールバーには次の操作を配置する。

- ベース画像読み込み
- 選択ツール
- 画像追加
- テキスト追加
- 図形追加
- ペンツール
- バケツツール
- 色選択
- PNG書き出し

### レイヤーパネル

レイヤーパネルにはレイヤー一覧を表示する。ユーザーは編集レイヤーの追加、選択、表示切替、重なり順変更を行う。ベースレイヤーは固定レイヤーとして表示し、編集不可であることを示す。

### プロパティパネル

プロパティパネルには選択中ツールまたは選択中オブジェクトに応じた設定項目を表示する。テキスト選択時はフォントと文字色を表示する。線選択時は線種、線幅、線色を表示する。図形選択時は塗り色、線色、線幅を表示する。

## レイヤー設計

レイヤーは表示順、表示状態、編集可否、所属オブジェクトを持つ。ベースレイヤーは編集不可の固定レイヤーとして扱う。編集レイヤーはユーザー操作によって追加、選択、表示切替、順序変更を行う。

レイヤー構成の初期状態は次の順序とする。

1. 上側編集レイヤー
2. ベースレイヤー
3. 下側編集レイヤー

表示時とPNG書き出し時は、下側編集レイヤー、ベースレイヤー、上側編集レイヤーの順に合成する。

## オブジェクト設計

オブジェクトは画像、テキストボックス、図形、線の4種類を扱う。各オブジェクトは所属レイヤー、位置、回転角度、拡大縮小率、表示状態を持つ。

画像オブジェクトはユーザーが追加した画像を表示する。テキストボックスは文字列、フォント、文字色、ボックスサイズを持つ。図形オブジェクトは形状、塗り色、線色、線幅を持つ。線オブジェクトは座標列、線種、線色、線幅を持つ。

## 描画機能設計

描画機能はポインター入力を使用する。マウス入力とタッチ入力を同一の入力イベントとして扱い、ドラッグまたはタッチ移動の軌跡を線として記録する。

通常線は入力座標を連続した線として描画する。停止時に太くなる線種は、同一位置付近での滞留時間を計測し、滞留時間に応じて線幅を増加させる。

## 書き出し設計

PNG書き出しはブラウザのCanvas出力機能を使用する。書き出し処理は表示中レイヤーを下から順に合成し、1枚のPNG画像として生成する。

初期版ではPNG以外の形式を書き出さない。初期版では編集状態を復元するためのプロジェクトファイルを保存しない。

## 非対象範囲

初期版では次の機能を対象外とする。

- ユーザー認証
- クラウド保存
- 共同編集
- 外部サーバーとの同期
- プロジェクトファイルの保存と読み込み
- PNG以外の画像形式への書き出し
- ベースレイヤー自体の画像加工

## 技術方針

- アプリケーションは静的Webアプリケーションとして実装する。
- GitHub Pagesで配信できる構成にする。
- 編集キャンバスの実装基盤にはFabric.jsを採用する。
- 画像読み込みにはブラウザのFile APIを使用する。
- PNG書き出しにはCanvasの画像出力機能を使用する。
- 日本語入力はブラウザ標準IMEとFabric.jsのテキスト編集機能を利用する。
- APIキー、パスワード、秘密情報をソースコードに含めない。
- 外部サーバーを前提とする機能を初期版に含めない。
- 実装はシンプルな構成を優先する。

- 編集レイヤーの重なり順を変更できる。
- 編集レイヤーへ画像を追加できる。

- テキストボックスで日本語IME入力ができる。
- テキストボックスのサイズ変更に応じて文字サイズが調整される。
- マウス操作で線を描ける。
- タッチ操作で線を描ける。
- 複数の線種を切り替えられる。
