# GazouEditor

GazouEditorは、ブラウザ上で完結する画像編集ツールです。ベース画像を読み込み、その上下にある編集レイヤーへ画像、テキスト、図形、線、塗りつぶしを追加できます。

## 主な機能

- ローカル画像をベースレイヤーとして読み込み
- ベースレイヤーの固定表示
- 上側編集レイヤーと下側編集レイヤーの初期作成
- 編集レイヤーの追加、選択、表示切替、順序変更
- 画像、テキストボックス、四角形、円、直線の追加
- ペンによるマウス描画とタッチ描画
- 通常線と停止時に太くなる線種の切り替え
- バケツツールによる簡易塗りつぶし
- 文字色、線色、塗り色、線幅、フォントの変更
- PNG画像として書き出し

## 技術構成

- Vite
- React
- TypeScript
- Fabric.js

## 開発環境の起動

```sh
npm install
npm run dev
```

起動後、表示されたローカルURLをブラウザで開きます。

## ビルド

```sh
npm run build
```

ビルド成果物は `dist/` に出力されます。

## プレビュー

```sh
npm run preview
```

## 注意事項

- 初期版の保存形式はPNGのみです。
- プロジェクトファイルの保存と読み込みは未実装です。
- ユーザー認証、クラウド保存、共同編集は対象外です。
- APIキー、パスワード、秘密情報をソースコードに含めません。
